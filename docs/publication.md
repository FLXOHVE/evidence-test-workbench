# Publication scope

Prepared for publication on 2026-10-31. The author confirmed ownership of the original code. Project code and the new generic case-design skill are distributed under the root [MIT License](../LICENSE). The portable skill includes its own copy.

## Included

Generic evidence-based case-design instructions, the reusable offline compiler dependency closure, CLI, synthetic examples, regression tests and CI. Source baseline hashes and current modifications are recorded in `SOURCE_PROVENANCE.json`.

## Excluded

Original delivery archives, customer/product requirements, historical workbooks, knowledge-base snapshots, credentials, internal service addresses, vehicle identifiers, live connectors, company-specific deployment scripts and bundled third-party skill collections.

The skill uses a separately supplied coding agent. The compiler consumes explicit contracts and does not call an LLM. Passing compiler tests does not establish requirement completeness, model output quality or real-product acceptance.

Publish this independent repository only. The parent workspace and original attachments are outside its public scope. Hosted CI results are available in the repository Actions tab after a push.
