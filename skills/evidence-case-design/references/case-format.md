# 用例和缺口的交付格式

优先使用用户或目标项目已有格式。没有约定时，可采用以下字段：

- ID / 标题 / 适用版本与范围。
- 来源：文件、章节或行、短摘录；区分原文与澄清答案。
- 风险与优先级：失败会影响什么，能否恢复。
- 准备：资源、数据、权限、初始状态以及确认起点的方法。
- 步骤：每步实际动作和对应的可观察预期。
- 清理：恢复本用例改变的对象或状态；只设计，不代表已执行。
- 结果：未执行。审核状态另列，不与执行结果合并。

覆盖缺口包含 ID、缺失规则/验证方法、受影响来源和用例、具体问题及当前状态。例：需求提到外部同步但没有定义触发条件，记录“同步何时触发、如何判断成功”，不填写“应在 3 秒内同步成功”。

对一项需求采用多条用例时说明区别，例如状态、输入等价类或失败后果；仅调换措辞不算增加覆盖。未指定非法输入如何处理时，可以记录“待确认的异常场景”，不能把经验推测升级为确定预期。
